AI Reply

v3.0.1 · native Android

A draggable floating bubble over any app — tap it, pick a tone, get one AI reply. Pure Kotlin, no account, your API key stays on your phone.

  • Z.ai GLM-4.5-Flash preset (default) + 5 more free AIs
  • 4 tones: Friendly · Professional · Playful · Fluent
  • Works on Android 7.0+, Quick Settings tile included
  • Built-in guide for the Android 13+ "Restricted setting" unlock
⬇  Download APK (4.5 MB) Download source code (.zip)
After tapping install, allow your browser to install unknown apps if Android asks. The app will guide you to enable the bubble overlay.
